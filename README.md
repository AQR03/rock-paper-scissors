# Rock Paper Scissors

A browser-based Rock Paper Scissors game built with vanilla JavaScript. Click a button to play a round against the computer, with running score tracking.

## Features

- Click Rock, Paper, or Scissors to play a round
- Computer randomly selects its choice
- Displays the result of each round (win, lose, or tie)
- Shows both players' choices after each round
- Tracks and displays a running score for player vs. computer

## Tech Stack

- HTML
- JavaScript (vanilla, no framework or build tools)

## Project Structure

```
.
├── index.html
└── script.js
```

## Getting Started

No installation or build step required.

1. Clone the repo
2. Open `index.html` in your browser

## Notes

- No overall "match winner" or game-end condition yet — score just accumulates indefinitely as rounds are played.
- No reset/restart button to zero out the score.
